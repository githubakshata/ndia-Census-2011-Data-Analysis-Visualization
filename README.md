# 🇮🇳 India Census 2011 Data Analysis & Visualization

Welcome to the **India Census 2011** project! This repository explores India's demographics using data analysis and interactive visualizations built with Python.

![India Census Banner](https://upload.wikimedia.org/wikipedia/commons/thumb/3/36/Census_of_India_2011_logo.svg/2560px-Census_of_India_2011_logo.svg.png)

---

## 📌 About the Project

This project leverages the **India Census 2011** dataset to uncover insights about the population distribution, literacy, sex ratio, and regional statistics of Indian states and districts.

### Key Highlights:
- 📈 Exploratory Data Analysis (EDA) on demographic data
- 🌍 Geospatial visualizations using district-level latitude/longitude
- 🧠 Insightful comparisons across states and districts
- 🖥️ Optional: Interactive Streamlit dashboard

---

## 🗂️ Dataset

1. `india-census-2011.csv`: Main dataset containing population, literacy, and sex ratio statistics by state and district.
2. `lat_long.csv`: Supplemental file containing coordinates for mapping.
